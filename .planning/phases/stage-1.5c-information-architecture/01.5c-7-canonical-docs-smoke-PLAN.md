# Architecture (canonical)

**Locked:** 2026-05-04 (Stage 1.5c)
**Source:** Jake nwrp43 + 1.5c discuss-phase + plan-phase outputs

## 8 Principles (canonical)

### Principle 1 — Data-first foundation
Every event in the lifecycle of a construction company is a data point. Every entity is queryable. Reports are emergent (queries against the graph), not hand-built features. The data graph is the moat — competitors who built feature-first can never catch up.

### Principle 2 — Knowledge graph data model
F1+ phases must build a relational entity-relationship knowledge graph, not isolated tables. See [ENTITY-INVENTORY.md](./ENTITY-INVENTORY.md) for the 31+ entity catalog. Plus relationships and audit trails for every entity.

### Principle 3 — Cost Intelligence is BOTH a layer AND destinations
Price Intel surfaces inline (estimates show learned cost ranges, invoice approval flags anomalies, selections show install costs) AND is its own primary nav section with destination workflows.

### Principle 4 — Cross-pollination of data on every ingestion event
When an invoice line item ingests, it enriches: Product entity, Vendor performance record, Cost Code data point, Selections Catalog entry, Job budget. ONE event, MULTIPLE entities updated.

### Principle 5 — Aggressive ingestion across modalities
Every input modality becomes structured data. See [INGESTION-ARCHITECTURE.md](./INGESTION-ARCHITECTURE.md).

### Principle 6 — Role-aware everything
Same nav structure for all users; visibility filtered per role. See [ROLES-CATALOG.md](./ROLES-CATALOG.md) for the 15+ default roles.

### Principle 7 — Today as personal home screen
Dashboard renamed Today. Always role-aware, action-oriented.

### Principle 8 — External access via magic links + universal applicability
Subs/architects/inspectors/owners act on Nightwork without full accounts. Profile-based feature flags support custom builders, remodelers, commercial GCs from one platform.

### Ingestion-is-data principle extensions
- Pay apps are ASSEMBLED FROM DATA (queries against time + invoices + COs for period), not manually built.
- Reports are queries.
- Estimates are guided queries against historical similar jobs.
- Selections track full lifecycle: picked → spec to sub → ordered → delivered → installed → warranty.
